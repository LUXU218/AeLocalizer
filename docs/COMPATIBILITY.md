# After Effects 兼容性

AeLocalizer 面向 Windows x64 上的 AE 2021–2026。「引擎」可分别控制效果名和参数名／下拉值。复选框文字由参数绘制路径处理，支持范围取决于实际打开的 AE 构建和目标控件。

## 运行时怎样判断

工具识别当前 AE 编辑进程及其加载模块，按功能验证需要的模块结构、入口和布局。本机保存的适配结果会与当前模块证据比对。无法验证的路径会保持停用。例如下拉布局无法确认时，可以保留参数名汉化并让该类下拉继续显示原文。可在「引擎」查看当前配置是否启用，在「设置 → 诊断」查看识别或恢复状态。配置已加载和挂钩就绪是运行状态，实际显示还要看目标控件是否命中词典。

## 下拉值的恢复与首次显示

- 写入异常或同一 AE 会话重连后，工具可能无法确认已恢复下拉文字。关闭「参数名与下拉值」后，如果菜单仍显示译文，请保存工程并重启 AE。AE 重启会重建当前会话的下拉控件。
- 新增效果、切换图层和首次展开菜单后的显示时延仍缺逐构建实测。静态识别、运行时挂钩记录和正常停用结果各自只覆盖对应的验证步骤。
